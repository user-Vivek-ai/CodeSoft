# Recommendation System

## Overview
This project is a Recommendation System developed as part of the CodeSoft Artificial Intelligence Internship.

The system provides personalized recommendations for Movies, Books, and Products based on user preferences and ratings. It features a responsive and user-friendly interface built using HTML, CSS, and JavaScript.

## Features
- Movie Recommendations
- Book Recommendations
- Product Recommendations
- Interactive User Interface
- Responsive Design
- Rating-Based Suggestions

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How It Works
1. User selects a category.
2. User provides preferences or ratings.
3. The system analyzes the input.
4. Personalized recommendations are displayed.
