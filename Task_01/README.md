# CODSOFT AI Internship Tasks

## Task 1 - Chatbot with Rule-Based Responses

### Overview

This project is a rule-based chatbot developed as part of the CODSOFT Artificial Intelligence Internship. The chatbot interacts with users through predefined responses and demonstrates the fundamentals of Natural Language Processing (NLP) using pattern matching techniques.

### Features

* Rule-based chatbot implementation
* Regular Expression (Regex) pattern matching for user input processing
* Interactive and responsive user interface
* Professional dark-themed web design
* Real-time conversation experience
* Built using HTML, CSS, and JavaScript

### Technologies Used

* HTML5
* CSS3
* JavaScript
* Regular Expressions (Regex)

### Project Structure

```
chatbot.html    # Web-based chatbot application
```

### How to Run

1. Download or clone the repository.
2. Open `chatbot.html` in any modern web browser.
3. Start chatting with the chatbot through the user interface.

### Learning Outcomes

* Understanding rule-based chatbot architecture
* Implementing pattern matching using Regular Expressions
* Building interactive web applications with JavaScript
* Designing professional and user-friendly interfaces
* Applying basic NLP concepts in chatbot development
